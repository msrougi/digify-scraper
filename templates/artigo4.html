Como Fazer Backup de Todas as Imagens do seu WordPress

📅 Janeiro 2025 · por Digify Scrapper · ⏱ 4 min

Perder as imagens do seu WordPress pode ser catastrófico — especialmente para lojas WooCommerce com centenas de fotos de produtos. Neste guia, você aprende como fazer um backup completo de todas as imagens em minutos.

Por que fazer backup das imagens do WordPress?

  • Migração de servidor ou hospedagem
  • Proteção contra falhas e hackers
  • Reutilização de imagens em outras plataformas
  • Arquivamento antes de redesign do site

Método 1: Usando o Digify Scrapper (mais rápido)

O jeito mais simples é usar o Digify Scrapper. Ele varre todo o seu site WordPress automaticamente e baixa todas as imagens da biblioteca de mídia em um ZIP.

  1. Acesse imagescrapper.digify.live
  2. Digite a URL do seu site WordPress
  3. Selecione profundidade 3 para garantir que todas as páginas sejam varridas
  4. Clique em Iniciar Scraping
  5. Baixe o ZIP com todas as imagens

💾 Faça o backup das suas imagens agora — grátis

Abrir Digify Scrapper

Método 2: FTP / File Manager

Acesse seu servidor via FTP e baixe a pasta completa wp-content/uploads/. Esta pasta contém todas as imagens e miniaturas geradas pelo WordPress.

Método 3: Plugin de Backup

Plugins como UpdraftPlus e BackWPup fazem backup automático incluindo a biblioteca de mídia. É a solução mais robusta para backups recorrentes.

Dicas importantes

  • Faça backup regularmente — idealmente semanal
  • Armazene o backup em local externo (Google Drive, Dropbox)
  • Inclua o banco de dados além das imagens
  • Teste a restauração periodicamente

WooCommerce: atenção especial

Lojas WooCommerce podem ter centenas de fotos de produtos. Use o Digify Scrapper com profundidade 3-4 para garantir que as imagens de todas as páginas de produto sejam capturadas.
